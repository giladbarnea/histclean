# hist

Zsh history hygiene tools.

## Commands

- `histclean`: interactively inspect and clean zsh history files
- `histmerge`: merge clean history snapshots into one time-sorted stream; use `--all` to widen auto-discovery to clean outputs and other history-like files
- `histcompare`: visualize history coverage, overlaps, and gaps

## Install

```bash
uv tool install -e .
```
