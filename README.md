# hist

Zsh history hygiene tools.

## Commands

- `histclean`: interactively inspect and clean zsh history files
- `histmerge`: merge clean history snapshots into one time-sorted stream; use `--all` to widen discovery and `--cleanup` to remove merged backup sources after successful output
- `histcompare`: visualize history coverage, overlaps, and gaps

## Install

```bash
uv tool install -e .
```
